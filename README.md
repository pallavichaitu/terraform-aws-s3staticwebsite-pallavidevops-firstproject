Overview

This project demonstrates how to provision and configure an AWS S3 bucket for static website hosting using Terraform Infrastructure as Code (IaC).

Features
Creates an S3 bucket.
Enables bucket versioning.
Configures static website hosting.
Uses Terraform for automated infrastructure deployment.
Applies tags for resource management.

Technologies Used
Terraform
AWS S3
AWS IAM
Git & GitHub

Resources Created
S3 Bucket
S3 Bucket Versioning
S3 Website Configuration

Learning Outcomes
Terraform resource creation
AWS S3 website hosting
Infrastructure as Code practices
State management basics
